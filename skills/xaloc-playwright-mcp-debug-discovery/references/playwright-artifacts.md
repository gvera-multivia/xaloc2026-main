# Playwright Artifacts

## Evidencia minima a conservar

- URL actual
- titulo de pagina si aporta contexto
- snapshot del punto roto
- mensajes de consola relevantes
- peticiones de red relevantes si hay API/redireccion/descarga

## Artefactos del repo

- `.playwright-mcp/`
- `.playwright-cli/`
- `screenshots/`

## Buen criterio

- una captura bonita no sustituye un snapshot util
- guardar solo artefactos que expliquen la rotura
- correlacionar el artefacto con el paso funcional y el archivo del site
