## 5) Troubleshooting

1. Site not found:
- Check `core/site_registry.py` registration.

2. Playwright timeout:
- Review selectors and waits in `flows/*`.

3. Bad payload fields:
- Inspect `tmp/*_mapped_*.json` and align with controller `create_target(...)`.

4. SQL driver errors:
- Verify ODBC driver and SQL connection env vars (`core/sqlserver_utils.py`).
